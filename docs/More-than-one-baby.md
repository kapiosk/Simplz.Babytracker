# More than one baby

With one baby nothing about the app changes. Everything below only appears once there are two.

## Adding one

The person icon in the header opens **Babies**. Type a name under *Add a baby* and tap **Add**.

A row of names appears under the header. Tap one to switch: **Track**, **Chart** and **Report** all
follow it, and each baby keeps a completely separate log. Nothing is ever shown side by side.

## Renaming

Same screen — the name is a text box, and it saves when you tap away from it. Everything logged
against that baby stays with it.

## Which baby a phone is showing

The choice is per device and it sticks, for months, the same way being signed in does. One phone can
sit on one baby while another phone sits on the other, which is what you want when there are two
parents and two babies.

The read-only password sees both and can switch between them.

## Entries logged before there was more than one

They all belong to the first baby. That happened once, automatically, when the second baby became
possible — nothing was lost and nothing needs sorting out by hand.
